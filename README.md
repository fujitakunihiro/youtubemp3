# YouTube → MP3

YouTube動画の音声をMP3として保存する、Windows向けのシンプルなGUIツールです。

## 使い方

1. Python 3.10以降をインストールします。
2. `setup.bat` をダブルクリックします（初回のみ）。
3. `start.bat` をダブルクリックします。
4. YouTube URLと保存先、音質を選び「MP3をダウンロード」を押します。

URLをまとめて保存する場合は、「TXTからURLを読み込む…」からURLを1行ずつ書いたテキストファイルを選びます。空行と `#` で始まる行は無視され、記載順にダウンロードします。読み込み後にメインボタンを押すと一括処理が始まり、保存先の中にTXTファイル名（拡張子なし）のフォルダを作って曲を入れます。失敗したURLがあっても残りのURLを続けて処理します。

初回セットアップでは `yt-dlp` とFFmpegをダウンロードするため、インターネット接続が必要です。YouTube側の変更に追従するには、ときどき `setup.bat` を再実行してください。

## 注意

自分で作成した動画、ダウンロードが許可された動画など、保存する権利のあるコンテンツにのみ使用してください。YouTubeの利用規約、著作権法、地域の法令を守って利用してください。

## 技術情報

- Python / Tkinter
- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- FFmpeg（`static-ffmpeg` がユーザー領域へ導入）
